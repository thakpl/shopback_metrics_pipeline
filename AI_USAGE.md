| **Design SQL logic for `avg_order_revenue`** | "How to calculate average revenue per order by customer in DuckDB when raw data is split between orders and order_items tables?" | Explained that a direct join can mistakenly calculate average revenue per item rather than per order. Offered two solutions: a two-step CTE aggregation and a mathematical shortcut using `SUM() / COUNT(DISTINCT order_id)`. | Adopted the mathematical shortcut query using `SUM(oi.price + oi.freight_value) / COUNT(DISTINCT o.order_id)`. This kept the query footprint compact and clean for our YAML setup while accurately accounting for shipping costs and unique orders. | Discovered the risk of data inflation when joining transactional tables with one-to-many relationships; learned how vital it is to align the aggregation grain with the target metric definition. |
| **Handle edge cases in YAML validation** | "My Python script crashes with `TypeError: 'NoneType' object is not subscriptable` when iterating through the `/metrics` folder. How do I fix this?" | Explained that the crash happens because the script attempts to index a `None` variable, which happens when `yaml.safe_load()` encounters an entirely empty file. Provided options for explicit `None` checks, `.get()` default fallbacks, or `try-except` blocks. | Implemented an explicit defensive validation step (`if metric is None: continue`) to gracefully bypass empty configurations within the loop, and switched structural lookups to the safe `.get()` method. | Learned that completely blank configuration files evaluate to a `NoneType` object in Python parsers; recognized the absolute necessity of defensive programming to secure data pipelines against corrupted metadata. |
| **Debug DuckDB execution error** | "DuckDB throws `Catalog Error: Table does not exist` when trying to query the table at the end of the script, even though the code looks correct. What went wrong?" | Suggested database catalog errors often originate from the "in-memory trap" (mixing global default connections with specific local connection objects), case sensitivity from double quotes, or active transaction timeouts. | Investigated my local setup against these hints and realized the code logic was clean, but an incorrect terminal Current Working Directory (CWD) caused the relative paths to miss the target YAML folder entirely. Resolved it by running the terminal from the project root and added explicit setup rules to the README. | Realized that debugging with AI requires auditing the local execution context alongside code semantics; observed how significantly the terminal execution directory impacts file-scanning utilities. |
